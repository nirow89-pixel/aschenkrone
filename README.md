# Aschenkrone

Aschenkrone ist ein düsteres Browser-Rollenspiel (HTML/JavaScript, ohne Installation).

**Jetzt spielen:** https://nirow89-pixel.github.io/aschenkrone/

## Lokal starten

Unter Windows `START-WEB.bat` doppelklicken (benötigt Python). Das Spiel öffnet sich dann unter
http://127.0.0.1:8766/web/index.html. Die HTML-Datei bitte nicht direkt öffnen, da die Bilder über `../assets/` geladen werden.
